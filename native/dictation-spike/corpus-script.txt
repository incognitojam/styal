# Corpus script for the dictation matcher.
#
# CODE:  read aloud. Contains identifiers written as they appear in code —
#        say them however you naturally would. The line as written IS the
#        expected output.
# PROSE: read aloud. Plain English, no identifiers. NEGATIVE CONTROL — the
#        matcher must leave these completely alone.
# FREE:  speak freely on the topic. No ground truth; used to hunt false
#        positives on realistic rambling speech.
#
# Identifiers are shown in code form deliberately. Spelling them out phonetically
# ("to string", "to jason") would dictate the pronunciation, which is the thing
# we are trying to measure rather than assume.
#
# Stumble freely. Restarts, filler words and self-corrections are useful data —
# the previous recording was clean reading, which is the easy case.
