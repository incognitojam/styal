# Importing data

Imports run from the client. Explain the steps and let the user run them.

The Welcome page offers Claude Code, Codex and Pi history import. Settings → About → Welcome page
opens it again.

The desktop app can copy cookies from another browser into a preview browser profile:
Settings → Browser → Browsing → Browser profiles → Add profile → Import from.
Quit the source browser first, except Safari, which can stay open but needs Full Disk Access
on macOS. This is a one-time copy.
