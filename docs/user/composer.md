# Message composer

Messages can contain up to 120,000 characters. If a draft is longer, T3 Code keeps it in the
composer and shows how many characters need to be removed. Shorten the draft or split it into
multiple messages, then send again in the same thread.

Drop images, source files, text, Markdown, PDFs, or other files onto the chat to attach them. A
message can contain up to 8 attachments, each no larger than 10 MB and totaling no more than 20 MB.
T3 Code saves each attachment in the connected environment and gives the agent its local path.
